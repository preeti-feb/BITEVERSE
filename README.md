# BITEVERSE

A static website built with HTML5 and CSS3 with animation effects.

## About this project

BITEVERSE is a modern, visually engaging food website designed to deliver appealing digital experience for those who enjoy to order food online.
It is made up of clean layouts, initiative navigation to create an enjoyable and more engaging part when order food 🍲 online.


## Features

- **Modern User Interface**
- **Clean Navigation bar**
- **Attractive Food Presentation**
- **Responsive design for Mobile 📱**

## Technologies Used

- **HTML5**
- **CSS3**
- **Git**

## Getting Started

To run or view this repository locally on your computer, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/preeti-feb/BITEVERSE.git
   ```
3. Open the project in VS Code
4. Open home_page.html in your web browser to view the project
